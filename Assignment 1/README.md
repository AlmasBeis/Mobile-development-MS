# Cinema Booking
Консольное Kotlin-приложение для демонстрации работы системы бронирования билетов в кинотеатр.
## Требования
- JDK 25
## Сборка и запуск
macOS:

```bash
./gradlew run
```

## IntelliJ IDEA
1. Открыть папку проекта через **File → Open**.
2. Синхронизировать Gradle. В **File → Project Structure → Project** выбрать JDK 25.
3. Открыть `src/main/kotlin/cinema/Main.kt` и нажать зелёный треугольник слева от `main`.
